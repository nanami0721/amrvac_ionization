# 原生散度诊断与径向边界验证（2026-11-16）

已实现原生散度输出，修复 Yin–Yang 径向散度修正的 ghost 更新顺序，并比较边界候选。对于当前光滑解析输运测试，建议采用已有径向离散散度修正作为后续试验配置。它显著降低散度，代价是约 2% 的局部磁场误差增加和约 6% 的演化耗时增加；尚未消除散度峰值的非单调收敛。运行时拼接仍为四点双线性插值。

## 实际代码修复

`fixdivB_boundary` 的径向模板需要角向 ghost 值。此前 `getbc` 先执行物理边界修正，再执行阴阳交换；在 patch 边缘会读取尚未填充的角向值。开启径向修正的 debug 实验在初始化阶段触发 SIGILL/浮点陷阱，详细 stderr 已保留在 `debug-fix/`。

修复后顺序为：径向物理 BC → 必要时阴阳交换 → 径向离散散度修正 → 阴阳交换。第二次交换传递修正后的径向/角向角点。初始化根据两侧 `boundary_divbfix` 与 special BC 配置解析逻辑开关，并在 world communicator 上对整数 0/1 求最大值，保证所有 rank 的 collective 次序一致。普通球坐标路径不启用该开关；未启用径向 special 修正的阴阳路径仍只交换一次。

最终初始化回归另发现：本机 MPI_LOGICAL/MPI_LOR 归约将各 rank 的真值归约为假值，诊断输出保存在 `isolate-trace/`。改用整数 0/1 的 MPI_MAX，避免依赖逻辑值表示；失败最终检查保存在 `release-debug-fix-failed-logical-reduction/`。

修复后的四组正反向、两种解析解 debug 检查均成功，stderr 为空。改动的公共代码在六种配置（1D1V、1D2V、1D3V、2D2V、2D3V、3D3V）完整库/依赖中编译通过；三维另有实际优化与 debug 可执行程序。

## 原生诊断的口径

测试模块直接调用 `get_divb`，包含最内和最外的物理单元，使用当前时刻刷新后的实际 ghost。诊断保存并恢复原状态，避免刷新过程改变后续演化；开关对照逐位比较快照。对解析场调用同一原生算子，并用独立的面面积/体积有限体积实现复核。

解析参考使用解析 ghost，不经拼接插值。故数值值减参考值同时包含演化、插值和边界处理影响，不能全部称为演化产生的散度。原生指标也不能直接与此前略去径向边缘的后处理指标混用。体积统计仍使用 16×16 角向子单元重叠权重。

## 正式复测结果

均为 TVDLF/MC（woodward）、三阶段、CFL=0.3、GLM alpha=0.5、4 个 MPI rank，t=0.6。每块网格为 16s×20s×52s。下表的散度包含径向边界层；不同指标不可互相替代。

|---|---|---:|---:|---:|
| 正向 / 1 | 解析值 | 0.065283 | 1.055458 | 0.484269 |
| 正向 / 1 | 径向散度修正 | 0.011387 | 0.079285 | 0.499149 |
| 正向 / 2 | 解析值 | 0.034881 | 0.747820 | 0.229039 |
| 正向 / 2 | 径向散度修正 | 0.011485 | 0.078977 | 0.234452 |
| 正向 / 3 | 解析值 | 0.020563 | 0.509579 | 0.125197 |
| 正向 / 3 | 径向散度修正 | 0.009042 | 0.083041 | 0.126968 |
| 反向 / 2 | 解析值 | 0.034133 | 0.748109 | 0.235906 |
| 反向 / 2 | 径向散度修正 | 0.011074 | 0.089516 | 0.240897 |

修正后的局部磁场 L1 中→细阶数为 1.513，并未达到二阶。熵脉冲中网格局部 L1 为 0.220308 → 0.220302，基本不变。

注意：修正后的全域散度最大值在三档网格约为 0.0793、0.0790、0.0830，未单调下降；RMS 在粗→中也未单调下降。径向第一层的离散散度本就受到该边界约束，不能将其下降当成独立精度认证。全域磁场误差、内部散度和反向实验必须一起看。本次反向只有中网格完整精度验证，没有反向三档收敛研究。

## 边界候选的取舍

另实现了参考解析解的 GLM 特征边界：令出射扰动 Wout=psi+ch*(Bn-Bn_exact) 从内部常数外推，入射扰动为零；改变磁场后补偿磁能以保持压力。中网格正向探索中，全域原生散度峰值从 0.748 降到 0.389，但去掉径向边缘后的拼接带峰值从 0.328 升到 0.369，因此不作为首选。减小 alpha 到 0.1 的匹配对照同样有区域间权衡，未改全局默认阻尼。

线性出射外推没有展示一致优势，且 debug 中出现 reference_br 非递归过程调用检查失败，未保留为支持选项；原型和失败日志保存在外部实验目录。最终支持的 radial_bc 只有 0（解析值）与 1（常数出射特征扰动）。特征法与径向 Bn 散度闭合互斥，测试入口与边界回调均明确拒绝叠加。

先前 `radial-fix/` 中的优化探索使用旧交换顺序，不计入正式验收。正式数据只使用 `verified-base/` 与 `verified-fix/`。

## 成本

在其他模拟结束后，关闭原生诊断，使用相同中网格、相同可执行程序、相同 100 步，做三对交替计时。最慢 rank 与平均 rank 的 build/pack/exchange/unpack 计时保存在 `performance/results.json`；由每个 rank 的 `/usr/bin/time -l` 独立记录峰值 RSS。

| 指标（三次中位数） | 原边界 | 径向修正 |
|---|---:|---:|
| 演化时间 / s | 13.969 | 14.771 |
| 最慢 rank 峰值 RSS / MiB | 313.64 | 313.94 |
| 最慢 rank exchange 累计时间 / s | 0.731 | 0.947 |
| 平均 rank exchange 累计时间 / s | 0.647 | 0.869 |
| 交换调用数 | 301 | 602 |

演化时间增加 5.74%。这是本地工作站、单一规模的计时，不是扩展性结论。额外交换复用已有缓存和缓冲区；原生诊断本身需要状态备份内存及文件输出，计时已关闭它。今后可 profiling 第二次交换中真正需要的径向角点数据，避免直接假定通信成本可以忽略。

## 拼接插值升级评估

在原生诊断下，最细网格修正方案的固定内部球壳（1.2<r<1.8）中：
- 实际 patch 边缘单元的最大散度 0.062928，RMS 0.007506。
- 离开边缘单元的最大散度 0.082196，RMS 0.009588。

因此实际输运尚未显示拼接边缘是压倒性的误差来源。静态探针另比较四点双线性与九点二次 Lagrange 插值：同一解析磁场，三时刻、正反向、两个 patch，以下取这些样本中的最大值。

| s | 插值点数 | ghost 磁场误差最大值 | 相对解析 ghost 诱发的原生散度最大值 |
|---|---:|---:|---:|
| 1 | 4 | 0.079856 | 0.211512 |
| 1 | 9 | 0.072291 | 0.171908 |
| 2 | 4 | 0.029524 | 0.131040 |
| 2 | 9 | 0.016702 | 0.071413 |
| 3 | 4 | 0.013950 | 0.093892 |
| 3 | 9 | 0.005587 | 0.040770 |

最细网格的静态误差分别改善约 2.5 倍、2.3 倍，但这不是 MHD 演化或守恒/正性验证。九点模板的原始插值槽位从 4 增至 9，去重后的实际 MPI 负担尚未测量。当前不升级运行时插值；下一步若原型化，应缓存九点权重与去重计划，加入正性回退，并用相同内部误差和整体成本比较，不能仅凭静态探针收益采用。
