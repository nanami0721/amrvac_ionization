# 低 beta 静平衡测试（2026-11-17）

**结论：不需要大网格就能发现实际的低 beta 精度问题。** 本轮所有模拟正常结束、密度和压力保持正定、stderr 为空；但粗网格在 beta=0.01/0.004 的短测中未达到预设精度标准。普通球坐标出现相近问题，不能归为阴阳拼接独有。方向加密与 CFL 对照支持角向空间离散误差的重要性，但未独立识别通量、几何源项、边界和 GLM 各自贡献。

## 方法与预先规定的验收

- 修改仅限测试定义和分析脚本，AMRVAC 核心源码哈希与上一轮六配置编译通过的版本一致。新增测试程序以标准 O3 和项目 debug 选项编译；四个 beta=0.004 的三步 debug 检查覆盖两种场型和两种网格。
- 新增 case=3：全局笛卡尔均匀磁场，rho=1、p=0.5、v=0，无引力；沿用 case=2：倾斜20度潜势偶极场与引力静平衡。密度和压力不变，仅增强磁场。
- beta_reference=2*p_base/B_pole^2。均匀场初始 beta 处处相同；偶极场这个值是解析表面磁极的 beta，实际单元内 beta 随位置变化，不能称全域 beta。
- 每 patch 为16x20x52单元，块8x4x4。阴阳2 ranks，普通球坐标1 rank；TVDLF/woodward、SSPRK3、GLM alpha=0.5、CFL=0.3。解析物理边界；没有压力修复、CT、Boris、额外热力学。
- 先扫描 beta=1,0.1,0.01,0.004 到0.1个声穿越时间，每0.02输出。仅两种网格在所有已保存时刻均达标的配对延长至1个声穿越时间，每0.1输出。没有延长未达标的低 beta 档位。
- 公共区域沿用 r=1.2..1.8、theta=60..120度、phi=100..190度。Mach RMS<0.01、Mach max<0.05、密度/压力/磁场相对L1<2%。另报告全域和边界/拼接分区；公共区域通过不等于全域每个单元都满足2%。
- 声学 Mach 用初始声速 sqrt(gamma*0.5)，Alfven Mach 用局部解析初始 |B|/sqrt(rho)。原生散度同时给出 raw、解析离散参考差值以及除以初始 |B| 的指标（壳厚L=1）。
- 比较固定声学时间，并非固定Alfven穿越次数：均匀场 t/tA=t/sqrt(beta)。降低 beta 会增加到达同一声学时间的步数。

## 当前结论与下一步

现有粗网格和GLM/TVDLF/woodward组合不能直接宣称适用于MFE论文级别的低beta日冕。它能在这些短测中稳定运行，但存在有物理意义的压力与虚假速度误差。普通球坐标与阴阳表现接近，角向加密有效，因此下一步应优先审计曲线坐标磁力/能量平衡和角向离散误差，再定向比较重构/通量或CT；不能仅凭本测试认定GLM或接缝是根因，也没有证据表明必须立刻上大规模计算。
