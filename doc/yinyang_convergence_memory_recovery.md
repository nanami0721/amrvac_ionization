## 保护及实际占用

监测每 0.2 秒读取进程树的 RSS 和 macOS physical footprint，以两者较大者与阈值比较。超限时终止本任务进程组及核对过进程启动时间的后代；监测出错也停止任务。这是采样式看门狗，不是内核硬配额，存在采样间隔内的超调。它不把 VSZ 虚拟地址空间当成物理占用，也不以此推断此前 1T 的来源。

64 MiB 阈值的 96 MiB 分配自测触发终止。实际四进程 s=2 半时间步实验也触发 2 GiB 阈值：采样 RSS 2062.89 MiB，physical footprint 1980.58 MiB，随后进程被终止，后续队列没有启动。该实验未完成，不计入精度结果。
